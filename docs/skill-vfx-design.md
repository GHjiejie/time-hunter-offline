# 刃锋技能特效重设计

依据《Godot 2D 多角色技能与特效设计实现指引》的动作、表现、规则分层方法，重做现有刃锋的技能表现。原有伤害、范围、消耗、冷却、连招和释放时点保持一致；当前改造覆盖已有剑士，不增加其他职业。

视觉统一为银白锋面、青色折光与少量细碎光点。普攻刀光贴近身体与武器，裂隙用紫青双向弧光说明范围，断界以金白裂痕和两翼收束终结。淡出使用每次效果自身的寿命，缩短多段效果叠加时间，减少闪屏、震动及火花数量。地面提示在人物下方绘制，避免遮挡身体。

| 动作 | 起手与释放 | 收招与特效 |
| --- | --- | --- |
| 三段普攻 | 第 1/2/3 段在 0.055/0.075/0.13 秒切换释放姿势并命中 | 紧凑银青弧光，前两段尾迹 0.20 秒，第三段 0.27 秒 |
| 瞬斩 | 0.30 秒沿世界坐标扫掠，锁定施放方向 | 收束速度线、四层渐淡残影和末端弧光 |
| 裂隙连斩 | 0.16 秒蓄力；0.16/0.38/0.68 秒释放三段 | 交替倾斜紫青刀光；普通段 0.24 秒，终结段 0.36 秒 |
| 终式断界 | 0.44 秒蓄力；0.44/0.66/0.90/1.28 秒释放四段 | 三次空间裂痕与金白双翼终结，终结尾迹 0.48 秒 |

`HeroRenderer.blade_anchors` 通过与人物相同的脚底支点、镜像、缩放、旋转和跳跃变换计算手部、剑根、剑尖位置。蓄力光绑定剑身；剑带按世界坐标保留最多 8 个采样，100 毫秒淡出，切换姿势帧、朝向、瞬移及结束动作时清理，渲染时仅加一次镜头偏移。

`ArenaModel.skill_released` 只通知表现层，释放声音在该事件播放。命中火花、受击声音、震动和停顿只由确认命中触发；挥空仍播放刀锋释放声音。暂停和命中停顿冻结动作、效果寿命、剑带、火花、闪光和镜头反馈。绘制不修改伤害或命中数据。

新素材由内置 image_gen 生成：[透明折光刀光](../assets/effects/refraction-crescent.png)，完整提示词见 [生成记录](../assets/effects/generation-prompts.txt)。透明 PNG 与程序弧线、渐隐剑带、碎片配合使用，资源保留在项目内。

验证使用 Godot 4.5.2 Compatibility：74 项战斗与存档检查、18 项技能缓存检查、77 项特效回归、25 项图形与输入检查，以及八姿势双向角色渲染检查通过。新回归覆盖左右冲刺去重、低帧率跨多个释放事件、挥空反馈、效果回收、暂停及命中停顿。实际场景双朝向展示共 644 帧，每帧确认绘制不修改效果或敌人生命值；[播放预览](skill-vfx-showcase.gif) 由这些截图生成。

当前动作仍基于已有八姿势图集与插值。桌面视觉和模拟检查已完成，Android 真机帧耗与触屏手感仍需设备实测。
