# 遗落港 P0 完整流程

按用户选定的「完整 P0 闭环」实施《Time Hunter Offline 玩法与功能建设指引》。文档示例结合源码调整为一名角色、三关、四类敌人与一个Boss；暂未扩展职业、商店、随机词条、成就或挑战模式。

此前已有刃锋、三波战斗、技能输入缓冲、音效与暂停，以及金币/强化/最高分的简单存档。本轮复用这些能力，加入稳定关卡、可见敌人规则、准备与结算、装备实例、经验成长、确定性奖励和可靠存档。

## 流程与机制

首次启动经开始游戏进入准备，选择外围后挑战。两组遭遇清完则确认经验、金币、双锋刃与断界，并解锁回廊；回廊首通解锁核心，击败核心守卫完成章节。可以立即进入下一关、再次挑战或整理装备。满级停止承诺经验收益。

三关同时改变敌人组合与空间边界。回廊缩窄横向范围，地面放电提前0.95秒预警；冲锋路线起手时锁定，射手瞄准后发射，重装正面减伤而绕后或普攻第三段破防。守卫使用横扫、冲锋和标记地面，半血转换0.9秒无伤害，再用不同顺序及双落点增加走位压力。

9件装备的属性由定义和实例推导，反复穿脱不累加。防御方向增加生命，代价是冷却或能量恢复；首通输出方向提高攻击并降低生命。连击被动要求2秒内3次普通攻击命中，返还6能量且有2秒间隔；反击仅由真正通过跳跃/瞬斩避开的敌人攻击触发，4秒内下一击+35%，有3秒间隔。受击无敌不触发反击。

广域裂隙范围120%、伤害80%，聚焦范围80%、伤害120%；精准断界范围70%、伤害130%。既有释放时间线、刀刃挂点和命中反馈沿用；技能可用状态由进度配置进入模型。设置能减少或关闭震动、闪光、额外火花和伤害数字，危险预警始终保留。

## 持久化承诺

出战记录含唯一ID、关卡、随机种子与即将开始的遭遇索引。生成每组敌人前保存断点，恢复时以独立种子重建。不会保存半途敌人位置、剩余生命或延时技能；恢复满资源，清空本次尝试的分数、计时与未入账补给。成绩时间代表本次尝试。

胜利奖励与首通、装备实例、等级、记录和出战关闭一起提交。重复回调被拒绝；结算写失败回滚全部变化并留在重试页。失败不支付奖励，也不扣已有装备与金币。主动退出确认放弃范围。

版本2存档先写临时文件并回读校验，再替换主文件；只有已验证的主文件能更新备份。旧版迁移保留金币、等级与原有技能，不虚构三关首通。未知版本或主备均损坏时保留原文件，确认新游戏才允许替换。新游戏重置进度与设置。
